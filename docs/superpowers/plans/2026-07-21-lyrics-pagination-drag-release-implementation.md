# 活字印刷、分组排序与 2.6.2 发布实施方案

## 目标

修复 Tauri 迁移后活字印刷无法使用、生成分组有数量但列表为空、分组标签无法自定义排序的问题，并生成签名的 2.6.2 Windows 发布产物。

## 实施步骤

1. 为源分组分页读取补回归测试，并通过 `library.queryPage({ groupId })` 读取完整有效素材集合，不再依赖内存详情缓存。
2. 为生成结果持久化补回归测试，把新分组、文件夹、素材关系和排序组成单次 `applyMutations`，等待事务完成后重新加载数据库。
3. 为分组排序补组件测试，以 Pointer Events 替换内部 HTML5 拖放，同时保留 Tauri 原生文件拖入。
4. 补齐 TXT 读取、生成及更新安装失败的显式错误状态，避免按钮永久停在进行中。
5. 运行 TypeScript、Vitest、Rust 测试和发布校验；修复发现的问题。
6. 将所有发布版本统一为 2.6.2，使用现有私钥构建签名安装包并校验更新元数据。

## 验收标准

- 冷启动时可从任意全局分页位置读取源分组全部素材并完成匹配。
- 生成成功后分组数量、列表内容和 SQLite 记录一致，重启后仍存在。
- 分组标签可拖动排序，外部音频文件拖入不受影响。
- 失败时界面退出忙碌状态并显示具体错误。
- 前端与 Rust 验证全部通过。
- 交付非空且版本一致的 `.exe`、`.yml`、`.json`、`.sig` 四个文件。
