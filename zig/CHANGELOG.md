# 变更记录

只记用户能感知的变化与关键数字。安装包与便携版在 `zig/dist/`，每次发布都带 `.sig`。

## 0.7.0（2026-10-31）

- **把文件夹拖进窗口就能导入**（`WM_DROPFILES`）：目录 → 走与按钮完全相同的导入路径；文件 → 明确拒绝，不猜父目录。
- nanoui 增加通用 drop 事件，未设置 handler 的窗口不会注册为投放目标。

## 0.6.0

- **首次启动不再是错误**：库文件不存在时打开空库并显示空状态，而不是 `FileNotFound` 崩溃退出；文件存在但损坏仍然具名报错。
- 修掉一个会污染列表的 bug：默认监听根是数据目录，**我们自己的缓存写入被当成新素材**（12 条的库涨到 30 条）。现在只有根目录里确实有本库样本、或显式 `--watch` 才监听。
- 修掉"首次导入后重启看不到素材"：默认库查找优先导入写出的 `.otto`。

## 0.5.0

- **窗口透明度**：设置面板滑块，拖动即生效；255（不透明）时移除 `WS_EX_LAYERED`，不改变默认上屏路径。
- `--d3d`（翻转模型）下打一行警告说明透明度可能无效。

## 0.4.0

- **更新链路闭环**：检查 → 下载（64 KiB 流式，64 MiB 上限）→ 流式 BLAKE2b-512 + Ed25519 验签 → 落盘 → 交给安装包。
- 验签失败或大小不符**立即删除 `.part`**，绝不把未验证的文件留在"可安装"状态。

## 0.3.0

- **设置面板**：置顶、更新源、内存/磁盘缓存预算；设置存在库旁边（dev 在 exe 旁），损坏回落默认值。

## 0.2.0

- **缩略图隔离**：第三方 Shell handler 移到 `otto-thumb-host.exe`，崩溃/卡死只损失一张图和一次重启；3 秒超时；Job 对象防孤儿。
- **L3 磁盘缓存**：热启动 8 张图提前约 100 ms，且完全不启动 helper。
- **监听溢出重扫**：防抖 500 ms，按身份匹配，改名不算增删。
- 性能基准 `--bench` 六项；内存优化 128.6 → 42.6 MiB；滚动实测 62.5 fps。

## 0.0.1 – 0.1.1

- 0.0.1 首个可分发版本：列表、缩略图、选择、拖出、Ctrl+C。
- 0.1.0 导入 + OTTOLIB 持久化 + 文件夹选择器。
- 0.1.1 把缩略图搬进独立进程。
