## 0.43.0

- **库加载离开关键路径**：读库挪到工作线程，与"创建第一个窗口"的那 58 ms 重叠；join 在首帧构建之前，**不会先画空列表再跳变**（两版显示列表与截图逐字节相同）。
- 同会话交替测量：首帧 p50 **88.3 → 83.6 ms**（墙钟）、内部 **78.1 → 72.3 ms**；把重叠关掉即回到原值。
- 字形栅格那 8 ms **量过没动**：129 个图集 key = 87 个字符 × 亚像素相位，首屏全都需要；跳过灰度面会让 `--d3d` 文字变空白。

## 0.42.0

- **vendor 升到 zig-audio v0.20.0**：库的代码没有变化，变的是"它能不能证明自己对"——短缓冲矩阵 182 格、截断/错误映射两张契约、20 个永久 fuzz 语料、每格式的分配与并发报告。
- 同步时排除 `src/fixtures` 与 `src/fuzz_corpus`（库自己的测试素材与语料，属于库仓库，不是副本的一部分）。

## 0.41.0

- **缩略图去重**：列表行 64px 与预览 256px 不再各取一次——预览取到的大图留在独立预算里，行内图由它盒式降采样派生（0.15–0.34 ms，工作线程）。反向绝不做：**任何 64px 请求都不会变成 256px 请求**。
- 缓存键补上 **provider 版本**与**像素格式**（`k2` 键格式版本）：provider 行为一变，旧像素不再命中。
- **覆盖式升级验收**：`fresh-user.ps1` 新增第 9 步——在同一个程序目录上把新版直接盖在旧版上（不先卸载），断言应用层逐字节等于全新安装、`library.otto` 与 `settings.json` 逐字节不变、旁边的便携副本纹丝不动、新版能读同一份库。
- 回滚策略显式为**零副本**（数据不在程序目录，回滚靠重装旧版），断言写成"0 份或恰好 1 份"并留了绊线。
- `fresh-user.ps1` 从 10 步 / 67 断言变成 **11 步 / 96 断言**；`-FaultDataLoss` 注入能让数据层 4 条具名失败。

## 0.40.0

- **helper 缺失契约统一**：默认隔离，helper 缺失/启动失败都是具名失败（`none.failed`），只有显式 `--no-isolation` 才回进程内；超时与崩溃**永不回主进程**。
- 每次 Shell 取图记录 `execution_domain=helper|in_process`，`--preview` 同时打印声明域与实际执行域。
- 新增 `zig\helper-contract.ps1`：6 种故障注入 + 6 组反向对照；**旧的 0.39.0 二进制跑同一脚本 6/6 失败**，证明闸门抓得住静默兜底。

## 0.39.0

- **按需 Tab 补全**：只在按 Tab 时对当前父目录枚举一次，连续 Tab 循环（`enumerations=1`）；只补目录，不逐键枚举、不后台搜索。
- **长路径**：452 字符的目录能列出并预览；只有真正调 Win32 UTF-16 的边界才按需补 `\\?\`，显示文本不无脑加前缀。
- **junction / 重解析点**：跟随目标、标链接，不递归展开；链接位复用行结构尾部空间，**每行净增 0 字节**。
- **Explorer 手感**：`Alt+D` 聚焦地址栏、`F4` 驱动器菜单、`F5` 刷新（选中按身份保留）；驱动器菜单显示卷标。
- 介质错误具名：`介质未就绪` / `路径不存在` / `没有访问权限`。
- `zig\browse.ps1` 从 38 项扩到 **49 项**。

## 0.38.0

- **可编辑地址栏**：`Ctrl+L` 聚焦全选，Enter 才跳转（**输入过程零磁盘 IO**），Esc 取消；相对路径、`..`、尾部 `\` 都支持。

- 地址栏、面包屑、盘符与点击目录**共用同一条导航与历史**，返回仍按文件身份找回选中项。
- 错误是具名的：`路径不存在` / `不是目录` / `没有访问权限`，不跳转也不崩。
- `zig\browse.ps1` 从 27 项扩到 **38 项**。

## 0.37.0

- **可以走进子目录了**：双击 / Enter 进入，`Alt+←/→` 前进返回、`Alt+↑` 上一级；历史按目录唯一记录，**返回时按文件身份找回选中项**（路径一样但内容被换过的文件不会误选）。

- 监听跟到当前目录（进新目录先关旧监听）；目录行的 `is_directory` 复用结构体尾部 padding，**每行净增 0 字节**。
- 大目录导航：10 万目录进入子目录再返回，峰值 **66 MiB**；零写入的递归指纹差异为 0。
- `zig\browse.ps1` 从 18 项扩到 **27 项**。

## 0.36.0

- **浏览模式的分页**：5 万条之后可以「加载更多」，从停下的地方续枚举（不是重扫）；10 万目录首末一致，峰值 **66 MiB**。
- **内存是硬判据**：每行实测 **637 B**，加载前先预测，超过 90 MiB 就具名拒绝（`已到内存上限，剩余 N 条未加载`），不是悄悄停。
- **重扫窗口不再丢事件**：事件带单调序号，重扫在飞期间不消费队列，扫完补应用；期间拷入 50 个文件，最终行数与磁盘一致。
- **监听硬错误可恢复**：目录消失显示「路径不可用（点击或滚动时重试）」，恢复由**下一次交互**触发，不引入定时器。
- `zig\browse.ps1` 从 12 项扩到 **18 项**；三套测试 84 / 190 / 333。

## 0.35.0

- **目录浏览 Stage 0**：`otto-lite <目录>` 直接打开真实目录、选中即预览，**不写任何库文件、不碰源目录**。
- 懒枚举：1 万文件首屏 **2.75 ms**、10 万文件（截断在 5 万，显式标记）峰值 **53 MiB**；滚动仍 62.5 fps。

- `zig\browse.ps1`：12 项验收，含"源目录 1 万条目前后快照差异 = 0"。

# 变更记录

只记用户能感知的变化与关键数字。安装包与便携版在 `zig/dist/`，每次发布都带 `.sig`。




## 0.32.0

- **全新用户测试脚本化**：`zig\fresh-user.ps1` —— 造临时下载/程序/数据目录、验签、静默安装、首启、导入、卸载、换版本、零污染，**61 条断言、3 秒**；连"改一个字节的副本必须验签失败"这种反向对照都在里面。
- 顺带修掉 `health.ps1` 头部自称 UTF-8 BOM 实际没有的问题（PS 5.1 会按 ANSI 读中文表头）。
- `zig\prune-dist.ps1`：dist 从 101.6 MB 降到 12.3 MB；**发现"删分发物会让测试静默变少"**，于是保留测试引用的版本。
- 清掉四个已合并的工作树（2.8 GB）。

## 0.31.0

- **基准不再把"显示器多快"当成"我们多快"**：`--no-vsync` 只作用于基准的屏外窗口，`scroll.ps1` 输出三行（gdi / d3d 关 vsync / d3d 开 vsync），断言只在前两行。
- 修正常被引用的内存口径：47.7 MiB 是 **debug**，release 是 41–43 MiB。

## 0.30.0

- **nanoui 升到 0.9.1**（上游 `018a504`），我们的两条补丁 rebase 上去：`no_activate` 与上游的 `non_activating` 合并、`Content` 移到独立文件、`tools/ios` 与 `tools/android` 必须随副本一起拷（否则报错完全不指向真因）。
- 上游带进了 GPU 渲染器，`--d3d` 从"另一条 CPU 上屏路径"变成"GPU 整帧"；**默认 gdi 路径一行未变**。

## 0.29.0

- **CELT 折叠区间少算一位**（不是 anti-collapse）：三个立体声素材从 47 / 83 / 94 dB 升到 **139 / 145 / 141 dB**，16 位输出误差 1 LSB。
- 测试判据从"实测值"**收回 90 dB 原标准**——只收紧，没放松。

## 0.28.0

- **Opus 立体声**：SILK 是 mid/side + 每帧预测权重（不是两路独立流），Hybrid 逐声道相加；8 kHz 重采样补上尾帧 flush，窄带素材 144 dB。
- 库升级又一次让应用里"它必须谢绝"的断言过时；谢绝语义换到"一包多于两帧"这条仍然不支持的路径上。

## 0.27.0

- **Opus Hybrid 可播**：同一帧里 SILK 与 CELT 共用一个算术解码器，CELT 从 SILK 停下的那个比特位接着解（通常不在字节边界）。

## 0.26.0

- **Opus 语音（SILK）可播**：对 ffmpeg f32 145.30 dB、s16 1 LSB；重采样复刻的是**被对比的那个实现**的算术（两个解码器彼此差 47 dB）。
- 8 kHz 路径的尾巴仍是已知差距（参考实现用镜像 flush，我们不复刻），如实记录。

## 0.25.0

- **Opus 的 CELT 层接入**：`.opus` 里的音乐类文件自解码播放（对 ffmpeg f32 SNR 94–142 dB，逐样本 max_diff 2 LSB）。
- **语音帧明确谢绝**：SILK/Hybrid 是"完好的文件用了我们没有的编码"，返回 `unsupported` 而不是 `failed`——注册表继续问下一个，用户不会被告知文件坏了。
- `.ogg` 同理：装 CELT Opus 能播，装 SILK Opus 谢绝；判定依据是内容不是扩展名。

## 0.24.0
