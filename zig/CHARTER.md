# 项目宪章

> **一个 Windows 原生的素材管理器：用分级缓存把「找音 → 试音 → 拖出」的每一步压到
> 可见阈值以下；界面由 nanoui 承载并随需求向上游生长。**

这份文件定义"我们做的是什么、不做什么、怎么算做到了"。任何偏离它的改动，应该在
PR 里说明理由，而不是顺手做掉。

---

## 一、三根支柱

### 1. 分级缓存：比资源管理器更懂"哪些东西值得常驻"

资源管理器的模型是「每次打开 = 每次重新读」。我们的模型是「读一次，之后按热度
分层持有」。层级不是拍脑袋定的，是按单位成本排的：

| 级别 | 内容 | 单条成本 | 何时产生 | 驻留策略 |
| --- | --- | --- | --- | --- |
| **L0** | 目录项：路径、大小、mtime | ~0.05 ms | 导入扫描 | 全量，索引 |
| **L1** | 头信息：时长、采样率、声道 | 1–5 ms | 导入后台 | 全量，元数据库 |
| **L2** | 解码 PCM + 波形峰值 | 20–50 ms | 首次试听 / 预热 | 有界 LRU + 热度保护 |
| **L3** | 波形落盘（sidecar 或内容寻址） | 一次 | L2 之后 | 磁盘，跨启动 |

规则：

- **L0/L1 永远全量**——它们便宜到可以忽略，而它们决定了列表能不能"一眼可读"；
- **L2 永远有界**——预算默认 256 MiB，可调到 1 GiB，但绝不允许无上限；
- **L3 是跨启动的部分**——这是"比 Explorer 好"最不显眼却最持久的一条；
- **淘汰按热度，不按插入顺序**——环形队列会误伤反复使用的那几个字。

### 2. 金属层：调用链上没有外来运行时

"零转义"的准确含义不是"不抽象"，而是**一次调用直达系统**：

- ✅ Zig 里手写 `extern` 直接对应 DLL 导出（`ole32!DoDragDrop`）；
- ✅ 允许 Zig 自己的抽象（模块、泛型、arena）；
- ❌ 不允许 WebView / JS 运行时出现在 UI 路径上；
- ❌ 不允许 C shim（`.c` / `.m` / `.java`）夹在中间；
- ❌ 不允许为了一个系统能力再起一个代理进程（除非该能力本身要求跨位数）。

这条规则解释了拖拽 helper 的存在：Melodyne 3.2.2 只接受 x86 源，那是**协议要求**，
不是我们偷懒。

### 3. nanoui 扩展版：一个 UI 树，而不是一层壳

UI 不是"套个网页"，也不是"每个平台各写一套"：

- 声明式视图 + 虚拟列表 + 自绘文字，全部在 Zig 里；
- 平台能力通过**同一份 `Options` / API** 暴露（无边框、透明度、IME、拖拽）；
- 缺什么补什么，补完提回上游——**fork 里不写 app-specific 的补丁**。

判断标准：任何一处改动，问"一个做音乐播放器的陌生人会需要吗"。不需要，就留在 app 侧。

## 二、非目标

明确不做，避免范围蠕动：

- **不做 DAW**：不处理音频、不做时间拉伸、不做混音；
- **不做播放器**：试听是手段，不是产品；
- **不做通用文件管理器**：只服务"素材 → 宿主"这一条路径；
- **不做跨平台优先**：Windows 是唯一一等公民（Melodyne / FL 都在 Windows）；
  其它平台保持能编译即可；
- **不做插件生态**：至少现在不做。

## 三、可度量目标

首版验收按这些数字，不按"感觉快了"：

| 指标 | 目标 |
| --- | --- |
| 冷启动（2000 样本库） | ≤ 100 ms |
| 常驻内存（不含 L2 缓存） | ≤ 50 MiB |
| 列表滚动 380×700 | 60 fps |
| 首次试听延迟（冷） | p95 ≤ 50 ms |
| 重复试听（热） | ≤ 5 ms |
| 拖出到 Melodyne 3.2.2 | 100% 成功，无 Bug Reporter |
| 拖出多文件（200 个） | 一次拖出，FL 正常接收 |
| 安装包 | ≤ 5 MiB |

## 四、与资源管理器的差异

"更好用"必须落在具体能力上，否则是口号：

| 能力 | 资源管理器 | 本项目 |
| --- | --- | --- |
| 元数据 | 每次打开重新读 | 索引，启动即可查询 |
| 波形 | 无 | 分级缓存，跨启动 |
| 跨目录搜索 | 慢 | 索引 + 拼音/首字母 |
| 试听 | 外部播放器 | 内联，毫秒级 |
| 拖出到宿主 | 系统默认 | 协议级实现 + 自动副本 |
| 分组 / 标签 | 无 | 一等公民 |
| 中文输入 | 系统默认 | 自己实现的 IME 路径 |
